# KojiKoutei（工事工程アプリ）

工事に特化した工程管理アプリと、その元データ（歩掛の日当り施工量）をまとめるリポジトリです。

## フォルダと担当

| フォルダ | 中身 | 担当 |
|---|---|---|
| `app/` | 工事工程表（HTML単体。Edge／Chromeで開き、共有フォルダのデータを読み書き） | 工程アプリのセッション |
| `bugakari/` | 歩掛 日当り施工量 抽出アプリ（積算基準書PDF → JSON） | 日当り抽出アプリのセッション |
| `bugakari/data/` | 抽出結果の JSON（例：`R08_日当り.json`）。工程アプリはここを読むだけ | 日当り抽出アプリのセッション |
| `docs/` | 設計メモなど | 共通 |

## 進め方
- 作業を始める前に最新を取り込み（pull）、終わったら push します。
- 自分の担当でないフォルダのファイルは書き換えません。必要な変更は相手側に依頼します。
- 積算基準書などの元のPDFは入れません（`.gitignore` で除外しています）。

## 目標とする流れ
1. 積算の入力データリスト（PDF）を読み込み、工種・種別・細別・数量・歩掛から工程表のベースを作る
2. 日当りマスタ（`bugakari/data/*.json`）から各歩掛の日当り施工量を選び、施工日数・暦日数を算定する
3. 人が先行・後続をつないで工程を組む
4. 工程計画作成支援システムで読み込める XML で出力する
5. 発注資料用に、工種だけの工程概要資料を Excel で作る
