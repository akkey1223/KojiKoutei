# 歩掛 日当り施工量 抽出アプリ

土木工事標準積算基準書（共通編・河川編・道路編 …）のPDFから、歩掛コード（施工パッケージ CB… ／ 施工歩掛 WB…）ごとの日当り施工量を抜き出し、根拠ページつきの表にまとめます。基準書は年度ごとに出るので、出力も年度ごとのフォルダに分けます。

## 準備
```
pip install -r requirements.txt
```
poppler の `pdftotext` がPATHにあれば、文字の読み取りが速くなります（無くても動きます）。

## 使い方
- 画面で使う：`python bugakari_app.py` → PDFを追加 → 「抽出して表を作る」
- コマンドで使う：`python bugakari_app.py 共通編.pdf 河川編.pdf 道路編.pdf -o 出力先`

共通編は必須です（日当り施工量の表「第Ⅰ編 第14章 ④ 作業日当り標準作業量」が共通編に載っているため）。河川編・道路編は、歩掛コードの一覧を作るのに使います。年度の違うPDFを混ぜると止まります。

## 出力（`出力先/R08_令和8年度/`）
| ファイル | 内容 |
|---|---|
| 日当り施工量_令和8年度.xlsx | 説明／コード別日当り施工量／日当り表（全行）／コード一覧／要確認 |
| 日当り施工量_令和8年度_コード別.csv | コード別シートと同じ内容（UTF-8 BOM付き） |
| R08_日当り.json | 工程アプリ読み込み用（コード → 条件ごとの日当り施工量）。そのまま `bugakari/data/` に入れる |

### このリポジトリでの置き場所
抽出した JSON は `bugakari/data/R08_日当り.json` のように「年度記号_日当り.json」の名前で `bugakari/data/` に入れます。工程アプリはここを読むだけです。積算基準書のPDFは入れません。

## しくみ
1. 各編の「施工単価入力基準表」から、コード・名称・施工単位・掲載頁・節（工種）を拾う
2. 共通編 Ⅰ-14-④ の表を罫線から読み取り、結合セルを補って「条件 → 日当り施工量」の行に分ける
3. 項目名・条件の文言（作業名など）・節名でコードと突き合わせ、確度を付ける
4. 施工歩掛（WB…）は、各歩掛のページにある日当り施工量の表（例：表4.3 日当り運搬量）を読み、単価表の摘要にある表番号でコードと結び付ける。こちらがあるコードは、Ⅰ-14-④ より優先する
   - A：名称が一致
   - B：名称が類似・部分一致、または入力条件の文言が一致
   - C：同じ工種の中の候補（人が選ぶ）
   - 計算：設置と撤去を1つのコードで扱う歩掛（敷鉄板など）の合成値 1/(1/設置+1/撤去)。設置・撤去の行の後ろに付ける

## JSON の daily[] の並び
コードごとに、元の表の並び（＝入力条件の選択肢の順）のまま出力します。並べ替えはしません。各行の `src`（基準書の頁）・`src_vol`（編）・`src_pdf`（PDFの頁）で根拠を確かめられます。

## 注意
- 値はすべて自動読取りです。工程の根拠に使うときは「根拠頁」で原本を確かめてください。
- 罫線の無い表や、見出しが表の外にある表は読み切れないことがあります。その頁は「要確認」シートに出ます。
